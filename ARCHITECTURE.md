# unproc — architecture & module contracts

iOS 26+, SwiftUI, Swift 5 language mode, no third-party dependencies.
Project is generated by XcodeGen from `project.yml` (never commit the .xcodeproj).
CI (`.github/workflows/build.yml`) builds on `macos-26` with the latest Xcode 26.

## Targets
| Target | Type | Sources |
|---|---|---|
| `Unproc` | app | `Unproc/App`, `Unproc/Shared`, `Unproc/Intents` — flag `UNPROC_APP` |
| `UnprocCapture` | ExtensionKit, point `com.apple.securecapture` (lock-screen camera) | `Unproc/CaptureExtension`, `Unproc/Shared`, `Unproc/Intents` — flag `UNPROC_EXTENSION`, extension-safe API only |
| `UnprocWidgets` | WidgetKit ext (Control Centre / lock-screen control) | `Unproc/Widgets`, `Unproc/Intents`, `Unproc/Shared/Core/Settings.swift` — flag `UNPROC_WIDGETS` |

Shared code must compile in the extension: never use `UIApplication.shared`;
go through `HostHooks`. Guard Photos-writing / LockedCameraCaptureManager code
that the extension must not use with `#if UNPROC_APP`.

## Pipeline (what "zero processing" means)
1. `CameraController` captures **RAW** with `photoQualityPrioritization = .speed`.
   Back lenses run on the best *virtual* back camera (triple → dual-wide →
   dual) so lens changes are zoom ramps, not session reconfigurations; a
   virtual camera has no Bayer RAW, so the back camera shoots **ProRAW** there.
   **Bayer** (default flavour, ProRAW optional) is used where the device is
   physical (single-camera phones). The frame's `lens.crop` is the residual
   crop relative to the constituent that took the shot (RAW is delivered at
   the constituent's native field of view). Lenses without RAW (front) fall
   back to a processed HEIF.
2. `Developer.develop` runs `CIRAWFilter` with: sharpness 0, local tone map 0,
   detail 0, boost ~0.5 (film-like not flat), modest luminance NR, lens
   correction on (distortion-free), no EDR. Orients, applies `lens.crop`.
3. `LookLibrary.apply` applies the selected Look (a procedurally generated 3D LUT).
4. `MultiExposure.blend` when double exposure is on.
5. `Developer.finish` encodes a Display-P3 JPEG (q 0.93) with original EXIF
   (orientation reset to 1), bundles the DNG if output is `.raw`.
6. A `CaptureSink` stores it: `PhotoLibrarySink` (JPEG as photo, DNG as
   alternate resource — one asset) or `SessionContentSink` (lock screen).

## Module contracts (Core types live in `Unproc/Shared/Core`)

### Camera — `Unproc/Shared/Camera/`
```swift
final class PreviewFrameBus: @unchecked Sendable {
    /// Handler is called on the video queue with each frame, already rotated to
    /// portrait (and mirrored for the front camera), in full 4:3 (w:h = 3:4).
    func setHandler(_ handler: (@Sendable (CIImage) -> Void)?)
    func publish(_ image: CIImage)
    /// EV the viewfinder must add to simulate a long shutter it isn't actually using.
    var previewGainEV: Float { get set }   // thread-safe
}

struct ExposureState: Equatable, Sendable {
    var isoRange: ClosedRange<Float>; var shutterRange: ClosedRange<Double>
    var biasRange: ClosedRange<Float>
    var iso: Float; var shutter: Double; var bias: Float; var kelvin: Float   // live values
    var manualISO: Float?; var manualShutter: Double?; var manualKelvin: Float?
}
struct FocusState: Equatable, Sendable {
    var lensPosition: Float          // 0…1 live
    var manualLensPosition: Float?   // nil = auto
    var point: CGPoint?              // normalized viewfinder coords, nil = centre
    var isTracking: Bool
    var trackedRect: CGRect?         // normalized viewfinder coords
}

@MainActor @Observable final class CameraController {
    enum Status: Equatable { case idle, running, unauthorized, failed(String) }
    init()
    let frames: PreviewFrameBus
    private(set) var status: Status
    private(set) var lenses: [Lens]          // ordered by zoom, front last
    private(set) var currentLens: Lens?
    private(set) var exposure: ExposureState
    private(set) var focus: FocusState
    /// Seconds the shutter is open right now (drives the screen dim), else nil.
    private(set) var openShutterDuration: Double?
    var proEnabled: Bool                      // false => full auto, continuous AF fixed at centre

    func start(preferredLensID: String?, rawFlavor: RawFlavor) async  // asks permission
    func stop()
    func select(_ lens: Lens) async
    func setRawFlavor(_ flavor: RawFlavor) async
    // Normalized viewfinder coordinates: (0,0) top-left, (1,1) bottom-right of the 3:4 portrait frame.
    func focus(at point: CGPoint)     // tap: one-shot AF+AE at point
    func track(at point: CGPoint)     // long press: Vision tracking, keeps AF on subject
    func resetFocus()                 // back to centre continuous AF, stop tracking
    func setManualFocus(_ lensPosition: Float?)
    func setISO(_ iso: Float?)
    func setShutter(_ seconds: Double?)   // may exceed what preview can run at: preview is kept ≥ 1/15 s-ish smooth, gain simulated via frames.previewGainEV
    func setExposureBias(_ ev: Float)
    func setWhiteBalance(kelvin: Float?)
    func capture(output: OutputFormat) async throws -> CapturedFrame
    /// Camera Control (iPhone 16+) : installs an exposure-bias slider and a Look picker.
    func installCaptureControls(lookCodes: [String], selectedIndex: Int, onSelect: @escaping @Sendable (Int) -> Void)
}
```

### Pipeline — `Unproc/Shared/Pipeline/`
```swift
enum LookLibrary {
    static let all: [Look]                       // all[0] == Look.zero
    static func look(id: String) -> Look         // falls back to .zero
    static func apply(_ look: Look, to image: CIImage) -> CIImage   // cached LUT filter, cheap enough for 60fps preview
}
final class Developer: @unchecked Sendable {
    static let shared: Developer
    let context: CIContext                        // Metal-backed, shared with the viewfinder
    func develop(_ frame: CapturedFrame) throws -> CIImage
    func finish(_ image: CIImage, look: Look, frame: CapturedFrame, includeDNG: Bool) throws -> DevelopedPhoto
}
enum MultiExposure { static func blend(_ first: CIImage, _ second: CIImage) -> CIImage }
enum ViewfinderEffects {
    static func gain(_ image: CIImage, ev: Float) -> CIImage
    static func zebras(_ image: CIImage, threshold: Float = 0.96, phase: CGFloat = 0) -> CIImage   // diagonal stripes over clipping areas
    static func peaking(_ image: CIImage) -> CIImage   // bright accent-coloured edges over in-focus detail
}
#if UNPROC_APP || UNPROC_EXTENSION
final class PhotoLibrarySink: CaptureSink { init(promptForAccess: Bool = true) }   // extension: false (never prompts)
#endif
final class SessionContentSink: CaptureSink { init(root: URL, library: (any CaptureSink)? = nil) }
    // writes <yyyyMMdd-HHmmss-SSS>-<id>.jpg (+ .dng), then saves to `library` (Photos) and writes <stem>.saved
enum SessionMarker   // <stem>.saved / <stem>.deleted JSON sidecars {localIdentifier, date}, atomic
```

### Host — `Unproc/App`, `Unproc/CaptureExtension`, `Unproc/Widgets`, `Unproc/Intents`
- `UnprocCaptureIntent: CameraCaptureIntent`, `AppContext = CaptureSettings`.
- Extension: `LockedCameraCaptureExtension` → `CameraScreen` with `SessionContentSink`/`SessionPhotoStore`.
  Each shot goes into the session directory (the lock-screen viewer lists its
  JPEGs) and, with the app's add-only Photos access (inherited; never prompted
  from the extension), straight into Photos even while locked — inside the
  shutter's `ExpiringActivity`. Success writes `<stem>.saved`; failure writes
  nothing, so the app imports it later. Deleting an already-saved shot in the
  lock-screen viewer (on commit, after undo is no longer possible) replaces
  `.saved` with `<stem>.deleted`, which outlives the image files.
- App: `LockedCaptureImporter` (app-only; pure scan/release rules in
  `LockedCaptureScan`) runs at launch, on every scene activation and on
  `sessionContentUpdates`. Shots with `.saved` are skipped and only cleaned up;
  marker-less shots are imported as the fallback (after `directSaveGrace`, so an
  in-flight direct save isn't duplicated); `.deleted` markers make it delete the
  asset in the foreground (`PHAssetChangeRequest.deleteAssets`, read-write access
  requested in the foreground; denied/declined → marker dropped). Files are
  deleted only once they're in Photos, and a session is invalidated only when
  nothing is left, the app is in the foreground and the session has been idle
  for `quietPeriod`. Pushes settings into the intent app context, disables idle timer.
- Widgets: `ControlWidget` button running `UnprocCaptureIntent`.
